# 操作影片腳本（約 3 分鐘）

錄影前：用 Chrome 開啟 https://f2855631.github.io/covid19-spread-simulator/ ，視窗寬度 1400 px 以上，先按一次「恢復校準值」。
每段的「畫面」是要做的操作，「旁白」是要說的話。

## 1. 開場（0:00–0:20）
- 畫面：停在首頁，日期 2020-02-26。
- 旁白：「這是 COVID-19 全球擴散模擬器。197 個國家各是一組 SEIR 模型，用真實的國際航線連起來，從 2019 年 12 月的武漢開始。」

## 2. 播放擴散（0:20–0:55）
- 畫面：把時間軸拖到 1/10，按「▶ 播放」，讓它跑到 3/15 左右按暫停。
- 旁白：「紅色弧線是最近 7 天的擴散路線，圓點是出現首例的國家。1 月下旬先傳到亞洲鄰近國家，2 月底之後歐洲、中東變成新的擴散樞紐。」

## 3. 關鍵擴散時機點（0:55–1:20）
- 畫面：在時間軸上方的類型按鈕只留「跨洲跳躍」，點下方表格裡「病毒首次到達歐洲」那一列。
- 旁白：「模擬器會自動找出關鍵時機點，依重要度排序；點一下就跳到那一天，地圖上會標出位置。」

## 4. 單一國家（1:20–1:50）
- 畫面：點地圖上的義大利；看右側曲線，再切換「SEIR」。
- 旁白：「點任何國家可以看它的每日確診，模型和真實資料疊在一起，也能看感染高峰日和總感染數。來源鏈顯示病毒是從哪裡傳進來的。」

## 5. 情境比較（1:50–2:35）
- 畫面：把「武漢封城日期」拉到 01/05，展開「逐國首例日比較」。
- 旁白：「如果武漢提早到 1 月 5 日封城，3 月底前出現病例的國家會從 176 國降到 62 國，各國首例日中位數延後 28 天。」
- 畫面：按「設為比較基準 A」，再把「封城後湖北對外移動減少」從 95% 拉到 99%。
- 旁白：「封得更嚴幾乎沒有差別，因為封城前病毒已經傳到 19 個國家。時間點比強度重要。」

## 6. 個體模擬（2:35–2:55）
- 畫面：切到「個體模擬」分頁，等到第 15 天按「立即封城」。
- 旁白：「同樣的道理縮小到一座城市：第 15 天封城，總感染人數少約九成；拖到第 25 天，只少一半左右。」

## 7. 收尾（2:55–3:05）
- 畫面：切回「全球擴散」，按「⬇ 匯出 CSV」。
- 旁白：「所有結果都可以匯出。資料、程式和驗證報告都在 GitHub 上。」
